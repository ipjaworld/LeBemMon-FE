# 레범몬

메이플랜드 이용자가 자신의 레벨에 맞는 몬스터와 이벤트 정보를 빠르게 찾고, 장비 조합을 미리 구성할 수 있도록 만든 개인 웹 서비스입니다.

- 서비스: [rebemon.xyz](https://www.rebemon.xyz/)
- 개발 기간: 2025.12 ~ 현재
- 개발 인원: 1명

> 메이플랜드 및 메이플스토리월드의 공식 서비스가 아닌 비공식 팬 프로젝트입니다. 게임 업데이트나 제보 출처에 따라 일부 정보가 실제 게임과 다를 수 있습니다.

## 프로젝트 배경

레벨 범위 몬스터를 찾으려면 여러 출처의 정보를 직접 비교해야 했고, 이벤트 드롭 정보 역시 지역과 알파벳을 기준으로 다시 탐색하기 어려웠습니다. 레범몬은 흩어진 정보를 하나의 탐색 흐름으로 정리하고, 출처의 신뢰도가 다른 데이터는 같은 사실처럼 단정하지 않도록 구분해 보여주는 것을 목표로 합니다.

## 주요 기능

### 레벨 범위 몬스터 검색

- 입력한 레벨을 기준으로 레벨 범위 몬스터 조회
- 레벨 80 이상에서는 레벨 70 이상 몬스터를 함께 제공
- 곧 레벨 범위를 벗어나는 몬스터와 파티 경험치 조건 표시
- 몬스터 이름·레벨·지역·속성 약점 필터
- 레벨, 경험치, 체력 대비 경험치, 지역, 이름 기준 정렬
- 인기 몬스터 보기와 최근 확인한 몬스터 기록
- 드롭 아이템과 출현 지역을 포함한 상세 정보 제공

### 이벤트 정보 탐색

- 이벤트 알파벳 드롭 몬스터를 지역별·알파벳별로 탐색
- 제보로 교차 확인된 정보와 추가 확인이 필요한 정보를 구분해 표시
- 이름 표기 차이를 정규화해 동일 몬스터의 중복·누락을 완화

### 장비 시뮬레이터

- 직업과 장비 부위에 따른 아이템 구성
- 장비 옵션과 업그레이드 수치 반영
- 캐릭터 능력치와 장비 결과 확인
- 브라우저 저장소를 이용한 프리셋 저장·불러오기

### 접근성과 검색 노출

- 모바일·태블릿·데스크톱 반응형 UI
- 페이지별 메타데이터, sitemap, robots.txt 제공
- 웹 앱 manifest와 서비스 아이콘 구성

## 기술적 특징

- Next.js App Router에서 검색 페이지의 메타데이터와 정적 데이터를 구성했습니다.
- 몬스터·지역·아이템·직업 데이터를 타입과 JSON 파일로 분리했습니다.
- 데이터 수집·정제·추가·검증 작업을 목적별 Python 스크립트로 관리합니다.
- 사용자 프리셋과 최근 조회 기록은 브라우저 저장소를 이용해 유지합니다.
- 데이터 이름 변형과 중복 항목을 정규화해 탐색 결과의 누락을 줄였습니다.

## 프로젝트 구조

```text
src/
├── app/          # 검색·이벤트·장비 페이지와 메타데이터
├── components/   # 검색, 카드, 상세 모달, 장비 시뮬레이터 UI
├── data/         # 몬스터·지역·아이템·직업 데이터
├── types/        # 도메인 타입
└── utils/        # 프리셋 저장과 문자열 처리 유틸리티

scripts/
├── parse/        # 원본 데이터 파싱
├── generate/     # 파생 데이터 생성
├── update/       # 기존 데이터 업데이트
├── add/          # 신규 데이터·필드 추가
├── fix/          # 중복 및 오류 데이터 정리
└── validate/     # 데이터 검증
```

데이터 관리 스크립트의 상세 사용법은 [`scripts/README.md`](./scripts/README.md)에서 확인할 수 있습니다.

## 로컬 실행

### 요구 사항

- Node.js 20 이상
- npm

### 설치 및 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.

### 검증

```bash
npm run lint
npm run build
```

현재 저장소에는 별도의 자동화 테스트가 구성되어 있지 않습니다. 주요 사용자 흐름은 로컬 실행 후 검색, 필터, 이벤트 탐색, 장비 프리셋 저장·복원 순서로 확인할 수 있습니다.
